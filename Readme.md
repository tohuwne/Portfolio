**Role:** Business Analyst & System Designer
**Date:** 4/2026

- **Requirement Analysis:** Applied BACCM framework to elicit requirements, managed User Stories and a Requirement Traceability Matrix (RTM).
- **Process Modeling:** Visualized AS-IS/TO-BE workflows using BPMN 2.0 to automate manual order and inventory synchronization.
- **System Design:** Architected a 3-tier system with UML (Use Case, Sequence, Class diagrams), designed a SQL Server DB.
- **Prototyping:** Built a functional WinForms prototype (C#) for core modules: Order Processing, Inventory, and Revenue Reporting.

### VibeTicket – Event Booking Platform (Course Project)
**Role:** UI/UX Designer & Requirement Analyst
**Date:** 7/2025

- **Workflow Optimization:** Designed streamlined user flows for Seat Selection and QR-based E-ticket Wallets, reducing transaction time to under 2 minutes.
- **Prototyping:** Created high-fidelity Figma prototypes focusing on visual hierarchy.
